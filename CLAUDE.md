# Release notes (admin → Novinky)

Every change a player or an organiser notices gets a line in `src/data/changelog.ts` in the same commit: in the entry with today's date at the top (create it if there is none, with a short title), in Czech, short, written from the user's side, `for: "players"` or `"organizers"`, `href` where it can be seen. Dependencies, CI, refactoring and invisible fixes get no line.
